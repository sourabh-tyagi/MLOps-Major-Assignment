⚙️ How It Works

  • Upload a face image using the file picker.
  • The system processes the image and prepares it for analysis.
  • A trained Machine Learning model analyzes facial patterns.
  • The image is compared with faces from the Olivetti Faces dataset.
  • The closest matching face class is displayed as the prediction.

📚 About Olivetti Dataset

  • Contains 400 grayscale face images.
  • Includes 40 different individuals.
  • Each individual has 10 face images.
  • Images are standardized to 64 × 64 pixels.
  • Widely used for Machine Learning and face recognition research.
Built using Flask, Scikit-Learn, Docker and Kubernetes
