# MLOps Major Assignment

## Overview

This project implements an end-to-end Machine Learning Operations (MLOps) workflow using:

* Scikit-Learn
* Decision Tree Classifier
* Git and GitHub
* GitHub Actions (CI/CD)
* Docker
* Docker Hub
* Kubernetes

The machine learning model is trained on the Olivetti Faces dataset and used for face classification.
